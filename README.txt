HOW TO PREVIEW
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.

HOW TO PUBLISH FOR FREE
Option A — GitHub Pages:
1. Sign in to https://github.com/
2. Create a new public repository named samyam0731.github.io (or another repository).
3. Upload index.html, styles.css, script.js, and the assets folder.
4. Open repository Settings → Pages and enable deployment from the main branch.
5. Wait for GitHub Pages to publish your site.
